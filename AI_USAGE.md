# AI Usage

I used Codex to help build and debug the backend. The app uses AWS Bedrock or Gemini to draft follow-up messages and answer chat questions. Staff reviews drafts; nothing is sent automatically.

I chose the features and API requirements, guided the implementation, and checked it with the automated tests, Postman, and cURL. I verified Bedrock live; Gemini still needs a configured API key for a live check.
